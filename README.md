# Creative Video Studio updates

This page lists improvements to the Creative Video Studio Grok Bot.

Each week, a copy of the bot reads `updates.json`, shows its owner anything newer than the version it has applied, and applies an update only after the owner says yes.

This repo holds only general bot improvements, never owner, client, or account data.

`client/hive` is the bot's opt-in Hive Mind helper. Sharing starts off, and the bot asks its owner before turning it on. When it's on, the bot sends a short, cleaned weekly list of lessons and feedback to the bot's creator. Names, handles, emails, links, and numbers are removed first.
